# Output Index

Use this when reviewer comments mention a figure, table, or generated CSV and you need to find the script that creates it.

From the repository root:

```powershell
.\scripts\run_script.ps1 code\find_output.R Fig1
```

Examples:

```powershell
.\scripts\run_script.ps1 code\find_output.R windrose
.\scripts\run_script.ps1 code\find_output.R light_response
.\scripts\run_script.ps1 code\find_output.R tambopata_48points
```

With no search term, it prints every output-like filename found in the R scripts:

```powershell
.\scripts\run_script.ps1 code\find_output.R
```

The index is generated by scanning the scripts, so it stays useful as long as new outputs are named in ordinary quoted strings such as `"Fig1_env_ENSO_faceted_MEAN_SD.png"` or `"some_table.csv"`.
